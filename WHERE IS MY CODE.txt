Open any .html or .css file with Notepad, Notepad++ or VS Code to read and
edit the code. Double-clicking opens it in the browser instead — to edit,
right-click the file and choose "Open with".

There is no JavaScript anywhere in this project. HTML and CSS only.

  style.css   ←──  THE ONE STYLESHEET FOR ALL 22 PAGES

    This single file controls how the whole website looks. The colours
    are at the very top in the :root block — change one value there and
    it updates on every page at once. About 1,700 lines.

  style-midnight-BACKUP.css     Old theme, kept in case you want it back
  style-celestial-BACKUP.css    Older theme, same reason
    ↑ these two do nothing unless you link them. Safe to ignore.

───────────────────────────────────────────────────────────────────────
  4. IF YOU BREAK SOMETHING
───────────────────────────────────────────────────────────────────────

This whole folder is inside OneDrive, so OneDrive keeps old versions of
every file. Right-click the file → Version history → pick a version from
before you edited it → Restore. Nothing you do here is permanent.

Before a big edit, copy the file first. style.css becomes style-COPY.css
and you always have a way back.
